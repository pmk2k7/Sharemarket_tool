எண் இலக்க இலக்கு கணக்கீட்டு கருவிகள் (Number Target Calculation Scripts)இந்தத் தொகுப்பு எண்களின் இலக்கங்களை (Digits) பகுப்பாய்வு செய்து, குறிப்பிட்ட வரம்புகளின் அடிப்படையில் மேல் மற்றும் கீழ்நோக்கிய இலக்கு மதிப்புகளைக் (Target Values) கணக்கிட உதவும் பைத்தான் ஸ்கிரிப்ட்களைக் கொண்டுள்ளது.📂 கோப்பு அமைப்பு மற்றும் விவரங்கள்1. dudle.py (இரட்டை இலக்க மேல் கணக்கீடு)ஒரு எண்ணின் கடைசி இரண்டு இலக்கங்களையும் (last1digi) முதல் இலக்கத்தையும் (fist1digi) பிரித்தெடுக்கிறது.   trad0 முதல் trad5 வரையிலான எண் வரம்புகளின் அடிப்படையில் எண்களைச் சரிபார்க்கிறது.   doubletar(a) என்ற செயல்பாடு மூலம் தகுந்த இலக்கு மதிப்பை உருவாக்குகிறத்து.   2. dudledown.py (இரட்டை இலக்க கீழ் கணக்கீடு)கொடுக்கப்பட்ட எண்ணின் இலக்கங்களை அலசி ஆராய்ந்து கீழ்நோக்கிய இலக்குகளைக் கணக்கிடுகிறது.   trad7, trad1 முதல் trad6 வரையிலான வரம்புகளைப் பயன்படுத்துகிறது.   doubledowntar(a) செயல்பாட்டின் மூலம் முடிவு மதிப்பைத் தருகிறது.   3. sing.py (ஒற்றை இலக்க மேல் கணக்கீடு)கடைசி ஒரு இலக்கத்தை அடிப்படையாகக் கொண்டு கணக்கீடுகளைச் செய்கிறது.   tars1, tars2, tars3 ஆகிய வரம்புகளைப் பயன்படுத்தி கடைசி இலக்கத்தைச் சரிபார்க்கிறது.   singtar(a) என்ற செயல்பாட்டைக் கொண்டுள்ளது.   4. singdown.py (ஒற்றை இலக்க கீழ் கணக்கீடு)ஒற்றை இலக்க கீழ்நோக்கிய கணக்கீடுகளுக்குப் பயன்படுகிறது.   tars1, tars2, tars3 வரம்புகளின் அடிப்படையில் singdowntar(a) செயல்பாட்டின் மூலமாக மதிப்புகளைத் திருப்புகிறது.   🛠️ பயன்பாடு (How to Use)இந்த நிரல்களை உங்கள் பைத்தான் திட்டங்களில் இறக்குமதி செய்து (Import) எளிதாகப் பயன்படுத்தலாம்:Pythonfrom dudle import doubletar
